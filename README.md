# RileyContext Public Agent Context

This repository intentionally publishes only the compact, privacy-screened context used by Riley's agents.

- Canonical file: `RILEY_CONTEXT.md`
- ChatGPT and browser agents: open <https://github.com/rileyfied/RileyContext/blob/main/RILEY_CONTEXT.md> directly; do not web-search for it.
- Raw transport URL: <https://raw.githubusercontent.com/rileyfied/RileyContext/main/RILEY_CONTEXT.md>. Intermediaries may cache this address; append a unique `?v=<UTC timestamp>` query when freshness matters.
- `Last Updated` records the latest successful pipeline publication date. The recent-activity marker is a routing hint, not project-status certification.
- Capture bodies, project files, local paths, runtime indexes, and source archives are not published here.

The full working repository is private: `rileyfied/RileyContext-private` on `main`.
Riley's prompts authorize Claude to fetch, search, read, and analyze relevant
private files through a working authenticated GitHub or workspace route. Public
context is an entry point, not a public-only access rule. Verify the actual
Claude connection and selected files; this directive does not grant authentication
or authorize publishing private content.

Historical clones, forks, and third-party caches created before the 2026-08-01 privacy migration may remain outside Riley's control.
